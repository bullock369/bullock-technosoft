# Bullock TechnoSoft — Full Responsive Animated Next.js Site

Theme:
- Primary: #24ACB7
- Navy: #062238
- Offer: #FFD21A

Pages:
- /
- /about-us
- /services
- /cctv-solutions
- /website-development
- /contact-us

Reusable folders:
- components/layout -> Header, Footer
- components/home -> home sections
- components/pages -> page-specific reusable blocks
- components/shared -> PageHero, SectionIntro
- data -> all service/content data
- lib -> company phone, WhatsApp, email, location

Animations:
- Header nav underline hover
- Header logo hover
- Buttons lift + shadow
- Cards lift + border/shadow
- Service image zoom on hover
- Icons rotate/scale on hover
- Footer links slide on hover
- Footer social buttons lift
- Hero devices float
- Offer shine animation
- Page hero entrance animation
- Card entrance animation with staggered delays
- Reduced-motion accessibility support

Install:
npm install
npm i lucide-react
npm run dev

Important:
1. Replace placeholder Unsplash images with your own business/CCTV photos.
2. Connect contact form to your API/email service.
3. Change company email in lib/constants.ts if needed.
4. The existing phone number is 9998829141.
5. WhatsApp is already configured for 9998829141.
